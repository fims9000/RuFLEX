# Stability Lab and Stability-Aware Review

RuFLEX records distinct sources of randomness. `split_seed` controls only data-partition membership; `training_seed` controls model fitting randomness. The legacy `seed` field is retained for compatibility: persisted objects without explicit seeds resolve it as both values and are labelled `LEGACY_COMBINED`.

`TRAINING_VARIABILITY` fixes one split and varies only training seeds. It is the only mode that produces fully matched case-level `StudyStabilityAnalysis` evidence: every run must share one dataset revision and the exact validation-case identity. `SPLIT_VARIABILITY` fixes training randomness while changing validation membership; RuFLEX persists aggregate metric dispersion but marks case-level agreement and HCIR `NOT_APPLICABLE` unless a separately declared intersection protocol exists. `COMBINED_VARIABILITY` changes both sources and is explicitly mixed split-plus-training evidence, not isolated training stochasticity. `LEGACY_COMBINED` is likewise not treated as fixed-split evidence.

`StudyStabilityAnalysis` is validation-only persisted evidence. It records the mode, study/run/dataset identities, both seed vectors, alignment status, raw-probability source, per-case run support, aggregate metric distributions, and per-case disagreement. HCIR has one persisted definition: selected-run raw confidence at or above the recorded threshold and class agreement below the recorded threshold, reported with its denominator and numerator. Close mean metrics, and high confidence from the selected run, do not prove stable individual decisions.

`StabilityGatePolicy` is a separately persisted, frozen validation-derived policy bound to the exact selected evaluation, study runs, model/dataset provenance and fit-case identity. It sends a case to `REVIEW` for machine-readable `LOW_CONFIDENCE`, `RUN_DISAGREEMENT`, `HIGH_DISPERSION`, or `INSUFFICIENT_RUN_SUPPORT`; a `GeneralizationContract` block takes precedence as `BLOCK` with `OUT_OF_SCOPE`. Explanation reproducibility is intentionally not a gate input: explanation stability is a separate evidence channel and is never inferred from prediction agreement.

Risk–coverage evidence includes no review, confidence-only review, and stability-aware review at matched accepted coverage. The optional random reference is deterministically selected from case identities, so persistence/reopen does not alter it. These validation descriptions do not establish superiority; A01 remains pre-freeze until a separately frozen experiment is run.

The final-test route can bind an already frozen Stability Gate policy to final-test evidence, but cannot fit or retune it. It verifies exact policy/evaluation/dataset/run provenance, and rejects a gate containing runs created after first final-test access. Any policy created after final-test access is rejected by the same dataset-level final-test firewall.
