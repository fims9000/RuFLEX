# Учебный проект: проверенный пользовательский маршрут

В окне создания проекта можно выбрать «Учебный проект · сохранённые данные (80 строк)». RuFLEX создаёт проект, сохраняет синтетическую таблицу с целевой колонкой `target` и открывает экран обучения. Обучение не запускается автоматически. Финальный тест остаётся закрытым, пока пользователь явно не подтвердит его открытие.

Список моделей на экране обучения формируется из runtime-каталога проекта: логистическая регрессия, дерево решений, случайный лес, градиентный бустинг, MLP и плоская нейро-нечёткая модель для поддерживаемой бинарной задачи. Это не обещание поддержки любого произвольного класса Python или AutoML. Доступные методы объяснения зависят от выбранной модели; проверенный маршрут для дерева использует Occlusion, а UI также предлагает применимые SHAP-методы.

Реальный браузерный тест `frontend/e2e/practice-project-full-route.spec.ts` подтвердил: сохранение 80 строк, выбор модели, обучение дерева решений, сохранение validation-оценки и F1-порога, построение и проверку объяснения Occlusion, явное открытие final test, закрытие и повторное открытие проекта с сохранённым результатом. Отдельные проверки подтвердили выбор модели через раздел «Модели» и маршрут MLP. Backend-тесты `test_runtime_generic_training.py` и `test_runtime_explainer_matrix.py` прошли; это не означает, что каждый метод объяснения применим к каждой модели.

Скриншоты этого маршрута: `screenshots/practice-01-create.png`, `practice-02-model-choice.png`, `practice-03-explanation.png`, `practice-04-final-test.png`. Результат на синтетических данных — только проверка работоспособности, не исследовательская оценка качества моделей.
