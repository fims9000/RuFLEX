# Alpha tabular models and saved evidence

This checkpoint verifies a human Studio route, not universal support for arbitrary data or model certification.

RuFLEX accepts declared CSV and XLSX tabular datasets. DatasetContract saves the source artifact, target, feature order and row identities; focused tests verify byte-identical source hashes and full table contents after close/reopen. Unsupported formats, invalid targets and incompatible tasks are not silently converted into a usable dataset.

The Studio model selector offers a binary logistic / continuous linear baseline, decision tree, random forest, gradient boosting, a flat neuro-fuzzy model, and now a one-hidden-layer MLP for binary classification or regression. Parameters shown for the selected model are validated before fitting. MLP exposes hidden units, epochs, learning rate, batch size and patience. A TrainingRun persists the declared settings, fitted declarative weights, artifact SHA, training and split seeds, feature order, TRAIN-only preprocessing identity and validation evidence. The reopened Studio shows its saved MLP architecture and settings. No pickle artifact is required for MLP replay.

For an MLP, persisted post-hoc occlusion and permutation SHAP explanations can be generated and checked against the exact run. These explain the fitted prediction, not causal effects. Manual Sugeno FIS rules remain editable in their dedicated workbench. A trained flat neuro-fuzzy model does **not** yet offer general editing of its learned rule structure; do not describe this as implemented. Validation-only comparison of already fitted models exists, but there is no automatic candidate generation or hyperparameter search in this checkpoint.
