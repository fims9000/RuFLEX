# Экран объяснения: график и раскрываемые детали

Локальное объяснение теперь показывает горизонтальный график сохранённых вкладов признаков. Направление полосы соответствует знаку вклада в показанный выход модели; длина нормирована только относительно наибольшего абсолютного вклада в этом же объяснении. Это не глобальная важность признака и не причинный эффект. При более чем восьми признаках график показывает восемь крупнейших по модулю, а полный набор чисел остаётся в раскрываемых подробностях.

В основном виде оставлены выход модели, график и краткий результат технической проверки. Входные значения, контракт, допущения, отдельные проверки и сведения о завершённой фоновой задаче раскрываются по запросу. Persisted ExplanationContract и ExplanationCheck не меняются; после повторного открытия проекта график строится из сохранённого контракта.

QA: русский браузерный учебный маршрут проверяет график, два признака, раскрытие полного контракта, закрытие/повторное открытие и тёмную тему. Отдельные browser regressions проверяют Occlusion, MLP и синтетический маршрут; frontend unit suite и production build пройдены.
