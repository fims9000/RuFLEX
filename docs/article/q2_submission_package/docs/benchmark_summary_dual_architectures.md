# Финальная сводка архитектурной серии RuFLEX

Краткая служебная сводка фиксирует результаты архитектурного обновления глубокого контура RuFLEX. Основная идея обновления состоит в том, что решающий слой перестает опираться только на последний скрытый уровень и получает доступ к исходным признакам и нескольким скрытым стадиям. Дополнительно используются перекрывающиеся локальные блоки.

## 3. Интерпретация

- На стандартной регрессии конфигурации с прямой передачей признаковой информации резко улучшают строгий последовательный глубокий контур, но по среднему RMSE еще немного уступают компактной конфигурации с одним скрытым уровнем.
- На стандартной классификации лучшие внутренние результаты уже дают именно такие конфигурации.
- На Covertype новая схема поступления признаков почти полностью снимает внутреннюю деградацию строгой последовательной схемы.
- На дополнительной проверке на увеличенных выборках конфигурации с прямой передачей признаков раскрываются сильнее, чем строго последовательный глубокий контур.
