# Финальный комплект статьи RuFLEX

В рабочем корне этого каталога оставлены только основные материалы текущей финальной версии.

## Основные документы

- `article_final_ru.md` — итоговый русский текст статьи
- `article_final_ru.docx` — итоговый русский текст статьи в офисном формате с встроенными рисунками, таблицами и оформленными формулами
- `article_extended_materials_ru.md` — расширенные материалы для соавтора
- `article_extended_materials_ru.docx` — расширенные материалы для соавтора в офисном формате с встроенными рисунками, таблицами и оформленными формулами
- `ruflex_platform_map_ru.md` — отдельная карта платформы: состав, модельные режимы, математика, результаты и границы утверждений
- `ruflex_platform_map_ru.docx` — та же карта платформы в офисном формате
- `neuront2026_short_ru.md` — краткая 4-страничная версия по шаблону NEURONT 2026
- `neuront2026_short_ru.docx` — краткая 4-страничная версия в формате DOCX
- `neuront2026_short_ru.doc` — краткая 4-страничная версия в формате DOC для загрузки в личный кабинет
- `neuront2026_short_ru.pdf` — PDF-проверка объема и верстки краткой версии
- `benchmark_summary_q2_final_plus.md` — краткая сводка по финальной benchmark-серии
- `visual_package_ru.md` — манифест финальных рисунков и boards
- `q2_submission_checklist_ru.md` — чек-лист оставшихся ручных шагов перед подачей
- `q2_build_report_ru.md` — технический отчет о последней автоматической сборке Q2-пакета

## Графические материалы

- `assets_q2_final_plus/` — финальные экспериментальные рисунки, boards и таблицы для Q2-версии статьи
- `generated_figures/` — схемы архитектуры и контура интерпретации
- `generated_equations/` — автоматически подготовленные изображения формул для офисной сборки

## Финальный пакет

- `q2_submission_package/` — собранный пакет для передачи соавтору или для финальной ручной вычитки
- `q2_submission_package.zip` — тот же пакет в архиве
- пересборка пакета выполняется скриптом `scripts/build_article_q2_package.py`
- пересборка краткой конференционной версии для NEURONT 2026 выполняется скриптом `scripts/build_neuront2026_short_doc.py`
- пересборка карты платформы в формате DOCX выполняется скриптом `scripts/build_ruflex_platform_map_doc.py`
- старые скрипты legacy-ветки сборки и metadata-helper'ы удалены из `scripts/`; исторические материалы сохранены только в архиве

## Архив

Промежуточные черновики, служебные версии, шаблонные сборки и старые article-материалы перенесены в каталог `archive/legacy_versions/`.
