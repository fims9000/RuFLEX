# Описания схем и рисунков для статьи RuFLEX

## Схемы

Схема 1. Архитектура платформы RuFLEX.
Схема показывает разделение внутреннего вычислительного модуля и платформенного слоя. В левой части выделен базовый вычислительный модуль платформы, который выполняет дифференцируемые нечеткие преобразования, вычисляет активации правил и обеспечивает базовые процедуры обучения. В правой части показаны платформенные модули, отвечающие за описание переменных, правил, обучение, интерпретацию, программный интерфейс и пользовательский контур.

Схема 2. Модельный контур RuFLEX.
Схема отражает два основных режима работы платформы. Верхняя ветвь соответствует плоскому интерпретируемому режиму, в котором фаззификация напрямую переходит к компактной базе правил и решающему слою. Нижняя ветвь соответствует глубокому нечеткому режиму, где после фаззификации строятся локальные блоки правил, скрытые нечеткие концепты и расширяемый пространственный каркас.

Схема 3. Контур интерпретации RuFLEX.
Схема показывает, как для выбранного объекта последовательно формируются степени принадлежности, активации правил, скрытые концепты и итоговый вывод. В нижней части вынесены аналитические материалы, которые платформа строит автоматически: графики фаззификации, анализ правил, анализ концептов и отчетные материалы.

## Рисунки

Рис. 1. Сравнение конфигураций платформы на задаче регрессии.
На рисунке приведено сопоставление плоских и глубоких конфигураций RuFLEX по основным метрикам качества на задаче California Housing Regression.

Рис. 2. Панель интерпретации для лучшей регрессионной конфигурации.
Рисунок иллюстрирует, как платформа отображает функции принадлежности, активные правила, скрытые концепты и сводные показатели модели для лучшей конфигурации в задаче регрессии.

Рис. 3. Сравнение конфигураций платформы на задаче классификации.
На рисунке представлено сопоставление конфигураций RuFLEX по метрикам бинарной классификации на задаче California Value Binary Geo.

Рис. 4. Панель интерпретации для лучшей классификационной конфигурации.
Рисунок демонстрирует визуальный анализ факторов, правил и скрытых представлений для конфигурации, показавшей лучший результат в задаче классификации.

Рис. 5. Пример функций принадлежности входного признака.
На рисунке показана интерпретируемая фаззификация одного из входных признаков, которая используется платформой при построении правил и последующей интерпретации результата.
