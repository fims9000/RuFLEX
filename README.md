НейроНечёткий Мастер

Лёгкое и красивое приложение на Python (Tkinter) для анализа данных с помощью нейро-нечётких моделей ANFIS.

Возможности:

    Загрузка и просмотр датасетов (CSV, Excel)

    Обучение и тестирование ANFIS-моделей (регрессия и классификация)

    Визуализация результатов и метрик

    Экспорт человекочитаемых правил

    Сохранение и загрузка моделей для повторного использования
