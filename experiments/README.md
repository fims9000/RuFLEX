# Experiments

Эта папка предназначена для воспроизводимых запусков RuFLEX, которые используются:

- для проверки платформы;
- для сравнения flat baseline и deep fuzzy feature learning;
- для подготовки таблиц и рисунков статьи.

Рекомендуемый порядок:

1. Запускать `study pipelines`.
2. Сохранять артефакты в подпапки вида `timestamp_pipeline_name`.
3. Лучшие запуски переносить или переиспользовать при сборке материалов статьи.
4. Финальные рисунки и таблицы выносить в `docs/article/assets/`.
