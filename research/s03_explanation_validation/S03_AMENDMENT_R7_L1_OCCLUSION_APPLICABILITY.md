# S03-R7 Amendment: artifact-level L1 applicability

R6 completed its immutable pre-corrupt foundation (15 model fits, 120 frozen
validation slots, 264 CLEAN contracts and 792 CLEAN evaluations) and its
deterministic Quantus refreeze before corrupt execution. R6 corrupt execution
was permanently interrupted after 16 artifacts and 48 evaluations exposed a
plan contradiction: L1/Occlusion was declared `NOT_APPLICABLE` while also
given an executable reduced-budget recipe. No L1/Occlusion artifact was made.

R7 is separately authorized. It inherits only R6 pre-corrupt CLEAN evidence
and the Quantus amendment. The 16/48 R6 corrupt outcomes are excluded from
all R7 estimates, confidence intervals, localization and runtime summaries.

R7 separates artifact applicability from validator-component applicability.
An artifact-level `NOT_APPLICABLE` condition has no corrupt contract, no
recipe execution and no validator evaluation. Exact Occlusion-L1 is excluded
because it has no meaningful reduced-fidelity computational budget. TreeSHAP-
L1 remains excluded because the corrected TreeSHAP route has no finite reduced-
fidelity route. No severity, metric, threshold, model, sample, explainer,
validator rule, localization rule or statistical procedure was changed using
R6 outcomes.
