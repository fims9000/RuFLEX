# Master specification

Study 01 evaluates (A) external computational conformance only for declared
semantic intersections, (B) reconstruction of native traces without calling
native inference, and (C) canonical serialization round-trip equivalence.  A
passing result never means symbolic real-number centroid integration, formal
verification, or equivalence with every external engine.

Primary Phase-A metrics are maximum absolute system error, system pass/fail
under frozen tolerance, and unexpected semantic mismatch count.  Prediction
outputs, trace reconstruction, and exchange round trips remain separate
claims.
