НейроНечёткий Мастер — это графическая программа на Python для анализа данных с помощью нейро-нечётких моделей (ANFIS). 
                       Приложение сочетает визуальный интерфейс и современные алгоритмы машинного обучения для решения задач регрессии и классификации. 
                       Реализованы средства для загрузки и изучения данных, настройки и обучения модели, визуализации результатов и получения человекочитаемых правил.

## Основные возможности

* `Загрузка данных`
Поддерживаются табличные файлы в форматах CSV и Excel. Приложение автоматизировано обрабатывает пропуски и подготавливает данные к анализу.
* `Анализ и статистика`
В приложении можно получить базовую статистику по колонкам, числовым признакам, увидеть количество строк, столбцов и пропущенных значений.
* `Корреляционная матрица`
Одним кликом можно построить и визуализировать корреляционную матрицу для числовых признаков.
* `Настройка и обучение модели`
В параметрах можно выбрать:
    - Тип задачи: регрессия или классификация
    - Число правил в модели
    - Тип функции принадлежности (Gaussian/Sigmoid)
    - Число эпох, размер батча, learning rate
* `Визуализация результатов`
Встроенные графики для анализа качества модели:
    - Для регрессии — scatter (разные типы), тепловые карты, гистограммы, остатки, boxplot ошибок.
    - Для классификации — матрица ошибок, распределение классов, scatter, ROC-кривая, Precision-Recall.
* `Оценка метрик`
    - Для регрессии отображаются значения RMSE, MAE, R².
    - Для классификации — Accuracy, Precision, Recall, F1.
* `Человекочитаемые правила`
Автоматическое извлечение и отображение правил модели на основе весов.
* `Работа с моделями`
    - Сохранение и загрузка обученных моделей вместе с нормализатором (scaler).
    - Получение новых предсказаний по новым данным с возможностью экспорта результатов.


## Краткое руководство пользователя

1. Запустите приложение.
2. Нажмите кнопку `Загрузить данные` и выберите файл.
3. Ознакомьтесь с высветившейся статистикой в левой панели.
4. При желании посмотрите корреляционную матрицу.
5. Выберите параметры в разделе `Параметры нейронечёткой системы`: тип задачи, число правил, тип MF, эпохи, размер батча, learning rate.
6. Нажмите «Выполнить анализ».
7. После завершения анализа:
    - Изучите извлечённые правила (слева).
    - Оцените метрики и графики (справа). При необходимости измените тип графика.
8. Можно сохранить правила (`Экспорт правил`) или предсказания (`Выгрузить предсказания`).
9. Для дальнейшей работы сохраните модель (`Сохранить модель`) или загрузите ранее обучённую (`Загрузить модель`).
10. Чтобы использовать сохранённую модель, выполните анализ на новых данных через `Анализировать с моделью`.
